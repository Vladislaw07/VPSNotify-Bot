# VPSNotifyBot

Telegram-бот для зберігання інформації про орендовані VPS та автоматичних нагадувань про наближення завершення оренди.

Бот дозволяє зберігати всі дані про сервери в одному місці: IP-адресу, логін, пароль, дату завершення оренди та опис проєкту, а також автоматично нагадує про необхідність продовжити оренду.

## Можливості

\* Додавання нових VPS.
\* Перегляд списку всіх збережених VPS.
\* Перегляд детальної інформації про конкретний VPS.
\* Видалення VPS із підтвердженням.
\* Перегляд статистики.
\* Автоматичні нагадування за один день до завершення оренди.
\* Перевірка коректності IP-адреси.
\* Захист від додавання VPS, що дублюються.
\* Зберігання даних у базі даних.

## Команди

| Команда              | Опис                              |
| -------------------- | --------------------------------- |
| /add_vps             | Додати нову VPS.                  |
| /list_vps            | Показати список усіх VPS.         |
| /delete_vps \<id>    | Видалити VPS.                     |
| /stats               | Показати статистику.              |
| /cancel              | Скасувати поточну дію.            |
| /help                | Показати довідку.                 |
| /start               | Розпочати роботу з ботом.         |

## Як це працює

Під час додавання VPS бот послідовно запитує:

- IP-адресу;
- логін;
- пароль;
- дату завершення оренди;
- назву або опис проєкту.

Після збереження бот щохвилини перевіряє терміни оренди та автоматично надсилає сповіщення за один день до її завершення.

## Використані технології

   Python 3.12+
   aiogram 3
   SQLite

## Встановлення

git clone \<repository_url>
cd VPSNotifyBot
pip install -r requirements.txt

Створіть файл .env та вкажіть необхідні параметри:

.env:
    TOKEN=your_bot_token


Після цього запустіть бота:

python main.py
